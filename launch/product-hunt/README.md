# Product Hunt launch assets

This folder is a draft launch kit. It does not indicate that Krater Pro has
been submitted, scheduled, featured, or published on Product Hunt.

## Files

- `listing.md` — submission copy, maker comment, FAQs, launch-day posts, and
  release checklist
- `positioning.md` — audience, value proposition, claims, and acquisition plan
- `thumbnail.svg` / `thumbnail.png` — 240×240 square thumbnail
- `gallery-01-one-agent.svg` / `.png` — 1270×760 CLI + IDE overview
- `gallery-02-smart-router.svg` / `.png` — 1270×760 Smart Router overview
- `gallery-03-workspaces-cloud.svg` / `.png` — 1270×760 project and Cloud Lab
  boundaries

The SVGs embed an unmodified copy of the canonical mark from
`web/src/assets/krater-pro-mark.svg`. Matching upload-ready PNGs are rendered at
their exact source dimensions. The validated Cloud Lab URL is
https://krater-pro.pages.dev/. Publishing still requires the maker's final
Product Hunt preview review.

Product Hunt's current guidance recommends a 240×240 thumbnail and 1270×760
gallery images:
https://help.producthunt.com/en/articles/479557-how-to-post-a-product
