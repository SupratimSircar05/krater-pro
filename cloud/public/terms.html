Know which surface you are using

Cloud Lab is a hosted virtual scratch workspace. It does not run your code or have shell, filesystem, or Git access. The downloadable local Krater Pro CLI and IDE are separate, open-source tools that can operate on projects you authorize.

1. The service

Krater Pro Cloud Lab lets an authenticated user save bounded virtual project files and chat history, connect a user-supplied Krater.ai API key for the current page session, and request coding assistance from the configured Kimi K3 model.

Cloud Lab is intentionally limited: it does not execute code, open a terminal, access a device filesystem, clone a repository, use Git, or deploy software. Descriptions of filesystem, Git, terminal, command-sandbox, or broader agent capabilities refer to the separate local Krater Pro CLI and IDE.
