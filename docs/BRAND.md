## Product name

The product name is **Krater Pro**. Use the full name in headings, window
titles, assistant labels, release copy, and first references. The installed
commands are `krater` and `krater-pro`; command names remain lowercase.

## Canonical mark

[`web/src/assets/krater-pro-mark.svg`](../web/src/assets/krater-pro-mark.svg) is
the single source of truth for the product mark. It depicts an illuminated
orange crater and orbital ring on a dark tile. The GUI imports this file for
the sidebar, responsive header, welcome view, assistant avatar, and browser
favicon.

Do not redraw, recolor, crop, rotate, or add text inside the mark. Preserve its
square aspect ratio and rounded corners. Use `◉` as the terminal-safe
monochrome counterpart where an SVG cannot be rendered.
